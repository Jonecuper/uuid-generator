# Генератор UUID

Этот проект представляет собой простую реализацию на PHP для генерации UUID (уникальных универсальных идентификаторов) разных версий: UUIDv3, UUIDv4 и UUIDv5. Каждая версия вынесена в отдельную директорию, где находится своя страница `index.php`, возвращающая UUID в формате JSON.

## Что такое UUID?

Универсальный уникальный идентификатор (UUID) — это метка объёмом 128 бит, используемая в программных системах для уникальной идентификации информации. UUID разработаны так, чтобы быть уникальными во времени и пространстве, без необходимости централизованного реестра.

Существует несколько версий UUID, каждая из которых генерируется по-разному:

- **UUIDv3**: Генерируется с использованием хеширования MD5 пространства имён (namespace) и имени (name).
- **UUIDv4**: Генерируется с использованием случайных или псевдослучайных чисел.
- **UUIDv5**: Генерируется с использованием хеширования SHA-1 пространства имён и имени.

UUID широко используются в распределённых системах, базах данных, идентификаторах сессий и других приложениях.

## Структура проекта

- `UUID.php` — Содержит класс `UUID` с методами для генерации UUID разных версий.
- `3/index.php` — Принимает параметры `namespace` и `name`, возвращает UUIDv3.
- `4/index.php` — Возвращает случайно сгенерированный UUIDv4.
- `5/index.php` — Принимает параметры `namespace` и `name`, возвращает UUIDv5.
- `readme.md` — Данный файл документации.

## Класс UUID

Класс `UUID` в файле `UUID.php` предоставляет следующие статические методы:

### `getV4()`

Генерирует UUID версии 4 с использованием случайных значений. Входные параметры не требуются.

**Пример ответа:**
```json
{"uuid": "123e4567-e89b-42d3-a456-556642440000"}
```

### `getV3($namespace, $name)`

Генерирует UUID версии 3 с использованием хеша MD5 от конкатенации UUID пространства имён и строки имени.

- `$namespace` — Строка в формате UUID (например, `6ba7b810-9dad-11d1-80b4-00c04fd430c8`).
- `$name` — Строка-идентификатор.

**Пример вызова:**
```php
UUID::getV3('6ba7b810-9dad-11d1-80b4-00c04fd430c8', 'myname')
```

### `getV5($namespace, $name)`

Генерирует UUID версии 5 с использованием хеша SHA-1 вместо MD5. Параметры те же, что и у `getV3()`.

**Примечание:** Пространство имён (namespace) должно быть корректным UUID.

### `isValid($uuid)`

Проверяет, является ли переданная строка корректно отформатированным UUID.

Возвращает `true`, если формат верен, и `false` в противном случае.

## Конечные точки (Endpoints)

### `4/index.php`

- **Метод:** GET
- **Ответ:** JSON с UUIDv4
- **Пример:**
  ```json
  {"uuid": "a1b2c3d4-e5f6-7890-g1h2-i3j4k5l6m7n8"}
  ```

### `3/index.php`

- **Метод:** GET
- **Параметры:** `namespace`, `name`
- **Пример:** `3/index.php?namespace=6ba7b810-9dad-11d1-80b4-00c04fd430c8&name=test`
- **Ответ при ошибке (400):**
  ```json
  {"error": "Параметры \"namespace\" и \"name\" обязательны для UUIDv3"}
  ```

### `5/index.php`

- **Метод:** GET
- **Параметры:** `namespace`, `name`
- **Пример:** `5/index.php?namespace=6ba7b810-9dad-11d1-80b4-00c04fd430c8&name=test`
- **Ответ при ошибке (400):**
  ```json
  {"error": "Параметры \"namespace\" и \"name\" обязательны для UUIDv5"}
  ```

## Требования

- PHP 7.0 или выше
- Нет внешних зависимостей

## Как использовать

1. Разместите все файлы на сервере с поддержкой PHP.
2. Откройте конечные точки в браузере или через HTTP-клиент:
   - Для UUIDv4: `4/index.php`
   - Для UUIDv3: `3/index.php?namespace=...&name=...`
   - Для UUIDv5: `5/index.php?namespace=...&name=...`
3. Убедитесь, что параметр `namespace` — это корректный UUID.
